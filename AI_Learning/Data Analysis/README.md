# Data Analysis

This folder focuses on turning raw data into insights using statistics, visualization, and analytical thinking.

## Goals
- Learn Python libraries for analysis, such as pandas, NumPy, and matplotlib
- Build data cleaning and exploratory analysis workflows
- Practice storytelling with data and dashboards

## Plan
1. Review data types, cleaning, and preprocessing
2. Explore descriptive and inferential statistics
3. Create charts and summary reports
4. Apply analysis to real-world datasets
