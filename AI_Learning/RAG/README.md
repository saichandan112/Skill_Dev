# RAG

This folder covers Retrieval-Augmented Generation, which combines information retrieval with language models for grounded answers.

## Goals
- Learn how LLMs can use external data sources
- Understand embeddings, vector stores, and retrieval pipelines
- Build simple RAG applications and evaluate quality

## Plan
1. Study vector databases and embeddings
2. Create a basic retrieval pipeline
3. Connect retrieved context to an LLM response
4. Test performance on real examples and improve prompts
