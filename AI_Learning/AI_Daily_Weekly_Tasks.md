# Daily & Weekly Tasks Roadmap — AI Learning Journey

This roadmap maps the learning material into actionable daily and weekly tasks, templates, and a 12-week milestone schedule you can follow.

---

## How to use
- Aim for consistent daily practice (30–120 minutes/day depending on availability).
- Weekly sessions consolidate learning: do at least one coding project activity per week.
- Use `LEARNING_LOG.md` to record daily/weekly progress and reflections.

---

## Daily Tasks (30–120 minutes)
Pick a time block and follow this template:
- 10 min: Quick review of previous notes / flashcards
- 30–60 min: Focused learning (reading, tutorial, or a coding exercise)
- 10–20 min: Hands-on practice or small step for a project
- 5–10 min: Log what you learned in `LEARNING_LOG.md`

Examples by skill
- Python: complete 1 kata or read a chapter
- Data Analysis: clean a small dataset or make one plot
- ML: run a model training for 10–30 minutes and inspect results
- Generative AI: test 2–3 prompt variants and save best prompts

---

## Weekly Tasks (3–10 hours spread across the week)
- Day 1: New concept deep-dive (read + take notes)
- Day 2–3: Hands-on exercises and small code snippets
- Day 4: Integrate code into your project repo (commit + PR draft)
- Day 5: Test, evaluate, and write a short summary
- Day 6: Create or update a README section or notebook
- Day 7: Rest or optional review / catch-up

Weekly Deliverables
- One completed exercise or one incremental project commit
- One short summary (200–400 words) in `LEARNING_LOG.md`

---

## 12-Week Structured Plan (Example)
Weeks 1–2: Python foundations + Git
- Daily: syntax practice and scripting
- Weekly: small Employee App milestone

Weeks 3–4: Data Analysis + Pandas
- Daily: EDA exercises
- Weekly: Data Analyzer mini project

Weeks 5–7: Machine Learning fundamentals
- Daily: model-building exercises
- Weekly: baseline ML model + evaluation

Weeks 8–10: Deep Learning + Generative AI
- Daily: experiment with small networks and LLM prompts
- Weekly: train a small model or build a prompt-based app

Weeks 11–12: RAG / Agents / Deployment
- Daily: work on vector stores and integration
- Weekly: deploy a minimal API using FastAPI + Docker

## Tips for Productivity & Retention
- Use spaced repetition (Anki / flashcards) for key concepts.
- Keep notebooks (Jupyter) for analysis and reproducible reports.
- Make small, frequent commits — each commit message should explain the why.
- Record short demo videos (30–90s) for portfolio projects.
