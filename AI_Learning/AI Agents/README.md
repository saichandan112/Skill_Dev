# AI Agents

This folder is for learning how AI agents reason, plan, and use tools to complete tasks autonomously.

## Goals
- Understand agent architecture and decision-making
- Explore frameworks such as LangChain, LangGraph, AutoGen, and CrewAI
- Practice designing agents for research, automation, and workflow support

## Plan
1. Study core concepts: prompts, tools, memory, and planning
2. Build a simple task-based agent
3. Test multi-step agent workflows
4. Document practical use cases and limitations
